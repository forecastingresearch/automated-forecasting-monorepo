Method

Each week, four frontier LLMs selected using the Epoch Capability Index research and forecast each question. Each model answers the same survey twice: once with full web access and once with forecastingresearch.org and its subdomains excluded. We take the median across models within each condition, then the median of the two condition medians for the headline forecast. Code and data: GitHub.
